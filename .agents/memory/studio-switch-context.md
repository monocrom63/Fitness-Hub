---
name: District studio context
description: Product boundary between the district manager's selected studio and organization-wide work.
---

Selecting a studio narrows operational work, but organization-level communication and team administration stay organization-wide. Course creation still requires an explicit target studio; the active studio is not permission to silently choose a course destination.

**Why:** The switch should prevent work from appearing under the wrong location without hiding cross-studio announcements or invitations. A saved choice must also win over an old room deep link once the manager explicitly switches again.

**How to apply:** For new views, decide whether their information belongs to one studio or the whole organization. Narrow studio-specific reads before result limits, retain server-side access checks, and reset or isolate in-flight page feedback when the selected studio changes.
